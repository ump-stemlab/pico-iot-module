Activity 6 — teacher notes

And, Or, Not. One idea: two questions joined into one.

What is being taught

  • One idea: and, or and not — joining questions so that one decision can depend on two things. The shape of an if does not change; only the question gets longer.
  • Open with the contrast. Activity 5’s exercise was deliberately two decisions. Today is one decision with two halves. Say that sentence out loud before anything else.
  • The trap: each half must be a whole question. This is Activity 5’s double-equals lesson one level up, and it carries the page (section #whole).
  • No elif. Kept out until Activity 9 on purpose, so the two-road picture survives. It will come up from someone who has looked things up; nothing here needs it.

The main program — two-key safety switch

# Two tools: Pin for the buttons and the light, sleep for the pause
from machine import Pin
from time import sleep

# SW1 and SW2 are buttons, held up until you press them
sw1 = Pin(2, Pin.IN, Pin.PULL_UP)
sw2 = Pin(3, Pin.IN, Pin.PULL_UP)

# LED1 is a light on GP11
led = Pin(11, Pin.OUT)

# One decision, asking about two things at once
while True:
    if sw1.value() == 0 and sw2.value() == 0:   # both held down?
        led.on()                                # only then does it light
        print("both keys held")
    else:                                       # one key, or none, is not enough
        led.off()
        print("locked")
    sleep(0.1)
  • Ten working lines. Exactly one of them is new.
  • The safety-switch story is worth thirty seconds: two buttons far apart means two hands nowhere near the blade. It is why and, not or, is the right word here.
  • Change the one word to or on the projector and run it again. That single edit is the clearest lesson on the page.

Exercise answer

Green LED3 (GP13) lights when at least two of SW1, SW2, SW3 are held. Three pairs, joined with or:

from machine import Pin
from time import sleep

# Three keys and one light
sw1 = Pin(2, Pin.IN, Pin.PULL_UP)
sw2 = Pin(3, Pin.IN, Pin.PULL_UP)
sw3 = Pin(4, Pin.IN, Pin.PULL_UP)
green = Pin(13, Pin.OUT)

# Three pairs, joined with or - any one pair is enough
while True:
    if (sw1.value() == 0 and sw2.value() == 0) or (sw1.value() == 0 and sw3.value() == 0) or (sw2.value() == 0 and sw3.value() == 0):
        green.on()
    else:
        green.off()
    sleep(0.1)
  • The thinking happens on paper. Listing the three pairs is the exercise; typing them is not. A class that starts typing immediately will produce two pairs and wonder why SW1+SW3 does nothing.
  • The question line is very long and that is fine. Say so, or half the room will assume they have gone wrong. Brackets round each pair are not compulsory but insist on them.
  • All three keys must also open it. If a pair “fixes” that with not, they have done the first going-further task — praise it, then ask for the plain version too.
  • Accept any sensible names. Nothing else in the program changes from the main one.

Before the lesson

  • Activities 1–5 done. Pin naming, the loop, print(), if/ else, == and both indent levels are all assumed and none is re-taught.
  • Check SW1 and SW2 on every board. A dead second button looks exactly like a wrong condition.
  • Two-finger test: students must be able to hold SW1 and SW2 down together. Some will need two hands.
  • Wokwi route: one extra pushbutton over Activity 5, three extra over that for the exercise.
  • Thonny preset to MicroPython (Raspberry Pi Pico); pin reference open on every machine.

Teaching notes

  • Do the joining words with people first. “Stand up if you have a phone and a pen.” Then or. The or round is the one that teaches — half the room sits down again because they think they must pick one.
  • The logic widget on the student page is worth five minutes on the projector. Hold one pad, then both, then swap the word. Nothing to type, and it shows the two halves being answered separately.
  • The dangerous mistake is worth staging. Type the bare-names version yourself, run it, and let the class work out why the light will not go out.
  • Keep not short. It is the third word, it is the fiddliest, and this activity only needs students to read it. The going-further tasks are where it gets written.
  • Nothing about indentation changed today. If someone is struggling there, the problem is Activity 5, not this page.
  • Safety rules unchanged: never 5V to a GP pin, never a power pin to GND, power off at SW5 before changing wires.
