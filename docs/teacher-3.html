Activity 3 — teacher notes

Servo Motor. The first time a student moves something physical — and the first time a number sent to a pin has three distinct meanings instead of two.

▶ Student page 📚 All teacher notes ← Activity 2 notes → Activity 4 notes 📌 Pin reference
Keep this link to yourself. Unlisted and hidden from search engines, but the repository is public — anyone with the URL can read it.

What is being taught

  • The one idea is the servo and PWM. A pin that flickers at a controlled rate, where the length of each pulse decides an angle. Nothing before today does this.
  • print() arrives here for the first time, deliberately early. Students see the Shell responding in real time to what the servo does, which makes it immediately useful and not abstract. Every activity from here on can use it. This was Kamil’s call (originally planned for Activity 4).
  • The pin trap is the hardest part, and it is not a mistake students will make once and not repeat. GP28 = GPIO18 (silkscreen) = header pin 12. Say it, put it on the board, and check wiring before every power-on.
  • VBUS not 3V3. The SG90 needs 5 V. A group that wires V+ to pin 1 (3V3) will see the servo twitch once and do nothing; the Pico survives but the experience is misleading. Check pin 2 before power-on for every group.
  • No for loops. This is a module-wide rule through Activity 8. The exercise is solvable with while True:, sleep(), print(), and duty_u16() only. Do not let students reach for a for loop.
  • One servo per pair on the real board. The Wokwi simulator gives each person their own, so the two experiences diverge here. Tell groups to disconnect before swapping who runs the code.
  • Reused, not re-taught: while True:, sleep(), variables, assignment, comments, and indentation are all from Activities 1 and 2. from machine import is from Activity 1. PWM was introduced in Activity 2 for LED dimming; here it is repurposed without being re-explained from scratch.

Common mistakes and how dangerous they are

MistakeWhat happensHow dangerous
Red wire in H1 pin 1 (3V3) instead of pin 2 (+5V) — one row out, not one pad out Servo twitches once, then nothing Not dangerous to hardware, but very misleading. Fix before anything else.
Orange wire in wrong pin (not pin 12 / GPIO18) Servo does not respond; no error Safe, just silent. Count along the top row of H1 carefully.
servo = PWM(Pin(18)) instead of Pin(28) Wrong pin activated; servo silent or another device moves Safe. Classic victim of the three-names trap. The silkscreen says 18; the code needs 28.
Missing servo.freq(50) TypeError or silent misfire Safe. The freq line must come before any duty_u16() call.
Servo arm already at stop position Arm appears not to move on one of the three steps Safe. Explain that the arm is already at the limit and cannot go further.
Exercise uses a for loop Works correctly Not an error, but against the module rule. Ask them to rewrite using only while True:.

Exercise answer — four custom stops

Code is shown as a picture — turn on JavaScript to see it.
  • The key requirement is four stops. Students who only rearrange the existing three positions without adding a fourth have not met it. Ask them to add one more variable.
  • Accept any four values between 1638 and 8192. The numbers in the answer above (3200 and 6500) are one possibility; 2000, 3800, 5500 would be equally correct.
  • At least one different hold time. The exercise says “make at least one hold time different from the others.” Two identical sleeps plus one different one meets this. Accept any variation.
  • A print() after each move. The message text is free — do not mark down a group that prints a number instead of a name.
  • The most common shortcut to watch for: copying the original three-stop loop and adding a fourth call without renaming the variable. Works fine; just confirm they understand what each number means.

Signal (PWM)OrangePin 12 (top row, 6th pad)GPIO18Pin 34 (GP28)GP28

All three are in the top row of H1, the 40-pin header along the top edge of the board: even pins run along the top row, nearest the board edge, odd pins along the bottom row. Pin 1 is the left-hand end of the bottom row, the corner nearest CN2 — so 3V3 (pin 1) sits below +5V (pin 2), and a red wire one row out is the classic failure.

Wokwi is a bare Pico, so the numbers there are the Pico’s own physical pins (40, 38, 34) — a different set of numbers for the same three connections. Do not read the H1 numbers onto the Wokwi diagram or the other way round.
