🔍 What this is

A MicroPython teaching module for the LilEx5 board.

The LilEx5 is a Raspberry Pi Pico W with three LEDs, a buzzer, buttons, a screen, a set of sensors and a long-range radio all built onto one board. These activities take you from switching on a single light to sending data across the internet — and then to a dashboard of your own.

Every activity gives you two routes

🧪 Wokwi — an online simulator

Just a web browser. Nothing to plug in, nothing can burn out.

🔌 The real LilEx5 board

The board, a USB cable and Thonny.

We always start in Wokwi Even when the real board is on the desk. On the LilEx5 the wiring is hidden inside the circuit board, so the simulator is the only place you get to see a circuit and build one yourself.

📚 The fourteen activities

Numbered exactly as they are in your Classroom. Each one adds exactly one new idea, and each one builds on the last.

✅ Before your first activity

1

Open the pin reference

Every part on the board has a GP number, and your code has to use the right one. Keep the pin reference somewhere you can see it.

2

If you are using the real board

Install Thonny and set the interpreter (bottom-right corner) to MicroPython (Raspberry Pi Pico).

3

If you are using the simulator

Just open wokwi.com. Nothing to install.

Three safety rules, every time Never connect a 5V pin to a GP pin — they are 3.3 V only. Never join a power pin to a GND pin. Switch the board off at SW5 before changing any wires.

🏫 For teachers

Each activity has its own teacher notes page — the exercise answer, before-the-lesson checks, teaching notes and a running list of which pins have been used so far. One index page links them all.
