Activity 0 — teacher notes

Getting Started. Two tools working, one tiny program, and the rules for the rest of the module.

▶ Student page 📚 All teacher notes 📌 Pin reference
Keep this link to yourself. Unlisted and hidden from search engines, but the repository is public — anyone with the URL can read it.

What is being taught

  • One idea: the Pico runs a program from top to bottom, instantly, with no screen or keyboard. Everything else is built on that.
  • The no-AI rule is not punitive. It exists because every program in this module is small enough to type, break, and fix. The skill is in the fingers, not in the prompt.
  • Two routes, same code. Wokwi first, then the real board. Students must see that the code does not care which machine runs it.
  • Errors are normal. The activity deliberately tells students to expect red text and to read it from the bottom up.
  • No pins today. That keeps the first day focused on tools, typing, and the shape of a program. Pins arrive in Activity 1.

The five-line program

Code is shown as a picture — turn on JavaScript to see it.
  • Line 1 imports a tool. Without it, sleep does not exist.
  • Line 3 starts a forever-loop. The colon is the most common first-day mistake.
  • Lines 4 and 5 are indented. Any mix of tabs and spaces will fail.
  • True has a capital T. This is the first place students meet case-sensitivity.

Going-further answers

TaskAnswer / what to say
Change the messageAnything inside the quotes works. Remind them the quotes must stay.
Change the speedsleep(0.5) prints twice a second; sleep(2) prints every two seconds. The number is seconds, and it can be a decimal.
Remove the colonSyntaxError: invalid syntax on the while line. The fix is the colon.
Change True to trueNameError: name 'true' is not defined. Capital letters matter.
Remove the indentationIndentationError. The lines inside the loop must be indented by the same amount.

Before the lesson

  • Every student can reach wokwi.com/projects/new/micropython-pi-pico from the school network.
  • Thonny installed, interpreter preset to MicroPython (Raspberry Pi Pico).
  • One LilEx5 board, Pico and USB cable per pair. Check SW5 on each board.
  • At least one spare USB cable that carries data, for the inevitable "Thonny cannot see it" moments.
  • The pin reference open on every machine — needed from Activity 1 onwards.

Teaching notes

  • Do not demo by copying code. Type it slowly, make a deliberate mistake, fix it. Students need to see that errors are recoverable.
  • Make them read the error out loud. "SyntaxError: invalid syntax" is meaningless until they say it slowly and point at the line.
  • The no-AI rule needs a reason. Explain that the final project has not been written down, so nobody can generate it. The point is not punishment; it is capability.
  • Self-paced starts after today. Today runs together because everybody needs the same two tools. From Activity 1, pairs move at their own speed.
  • Safety rules from day one: never 5V to a GP pin, never a power pin to GND, power off at SW5 before changing wires.
